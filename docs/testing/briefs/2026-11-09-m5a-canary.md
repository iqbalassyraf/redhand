## What changed (plain)
A **canary** is a fake marker the owner pastes into an agent's own system prompt. If that text later appears in a tool call (the call is refused) or in a tool answer (the text is hidden), the owner is alerted that the prompt "appears to have leaked". It is a new kind of honeytoken, so it reuses the existing detection; the gateway is unchanged. By default it refuses and alerts but **never freezes the agent**.
